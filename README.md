# 🎨 Commission Art Website — React

![Status](https://img.shields.io/badge/Status-Active-brightgreen)
![Framework](https://img.shields.io/badge/React-Vite-blue)
![Styling](https://img.shields.io/badge/TailwindCSS-38B2AC?logo=tailwindcss&logoColor=white)

Website portfolio untuk menampilkan layanan **commission art** seperti ilustrasi, fanart, dan desain karakter.  
Dibangun menggunakan **React (Vite)** dan bersifat **static website** — tanpa backend.

---

## 🚀 Live Demo

🔗 https://commissionstudio.vercel.app/

---

## ✨ Fitur

- 🖌 Showcase karya art dalam gallery
- 💸 Informasi harga & tipe commission
- 📱 Fully Responsive (Mobile Friendly)
- 📩 Contact CTA (menuju WhatsApp/Instagram/Email)

---

## 🧰 Teknologi

- React + Vite
- Tailwind CSS
- React Router

---

## 📦 Instalasi & Setup

1️⃣ Clone repository

```bash
git clone https://github.com/younggdev/commision-art-website
cd commission-art-website
```

2️⃣ Install dependencies

```bash
npm install
```

3️⃣ Run development server

```bash
npm run dev
```
